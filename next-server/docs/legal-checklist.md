# 이용약관 · 개인정보처리방침 체크리스트

본문은 `src/app/config/legal.ts` 에 있고 `/terms`, `/privacy` 가 그대로 렌더링한다.
초안은 2026-11-14 시점의 코드(Prisma 스키마, `lib/auth.ts`, 외부 API 연동)를 기준으로 작성했다.
법률 검토를 거친 문서가 아니므로, 공개 운영 전에 아래 항목을 직접 확인한다.

## 1. 공개 전에 확인·결정할 것

| # | 항목 | 현재 초안에 적힌 내용 | 확인할 것 |
|---|------|----------------------|-----------|
| 1 | 시행일 | 2026년 11월 14일 | 실제 배포일로 `LEGAL_META.effectiveDate` 수정 |
| 2 | 회원 탈퇴 | 이메일로 요청하면 운영자가 처리 | 탈퇴 API·화면이 없음. 수동 삭제 절차를 정하거나 탈퇴 기능 구현. `Comment`·`FragranceReview`·`Fragrance`·`ScanResult` 는 `authorEmail`/`userEmail` 관계에 `onDelete` 가 없어 User 삭제 시 처리 방식 결정 필요 |

## 2. 기능이 바뀌면 함께 고칠 곳

- 수집 항목 추가(예: 스키마의 `QuizSession` 취향 퀴즈를 실제로 열 때) → 방침 2항 표
- 외부 서비스 추가·교체(분석 도구, 결제, 메일 발송 등) → 방침 5항 표, 9항(추적 도구 미사용 문구)
- AI 모델·제공사 변경 → 방침 5·6항, 약관 제6조
- 유료 기능 도입 → 약관 제5조("무료")·제12조, 전자상거래법상 표시 사항 별도 검토
- 내용을 고치면 시행일을 갱신하고, 중요한 변경은 사전 공지
